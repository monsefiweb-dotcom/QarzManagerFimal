# Qarz Manager Final 4.0

A native Android debt manager focused on simple offline use.

## Included
- Professional dashboard and prominent Add Debt action
- I Owe / Owed To Me accounts
- Person name and phone
- Principal, paid and remaining balance
- Due date and overdue highlighting
- Payment history with notes
- Edit/delete accounts
- Search by name or phone
- Today/month/year reporting
- Pashto, Dari and English UI labels
- RTL-friendly Pashto/Dari content
- Dark mode
- PIN lock
- Backup to a text file
- Restore from backup file
- Offline local storage
- Codemagic build configuration

## Build
This is a native Android Gradle project. `codemagic.yaml` is at repository root.
Run `./gradlew assembleDebug` in a normal Gradle environment or use Codemagic.
